# CrateMind

Το CrateMind είναι ένα τοπικό εργαλείο για DJ, με προσανατολισμό στο psytrance, που σε βοηθά να καταλάβεις και να χρησιμοποιήσεις τη δική σου μουσική συλλογή. Σαρώνει τη βιβλιοθήκη σου, σου επιτρέπει να καταγράψεις τη δική σου γνώμη για κάθε κομμάτι (ενέργεια, ένταση, σκοτεινότητα, ρόλο στο set, κατάσταση, υποείδος, σημειώσεις), εντοπίζει διπλότυπα, προτείνει επόμενα κομμάτια με εξηγήσιμο τρόπο και εξάγει αρχεία που μπορείς να πάρεις μαζί σου.

Είναι σχεδιασμένο για έναν χρήστη, στον δικό του υπολογιστή. Δεν υπάρχουν λογαριασμοί ούτε συγχρονισμός στο cloud.

## Αρχή ασφάλειας δεδομένων

Το CrateMind διαχειρίζεται **μόνο τα δικά του μεταδεδομένα προτίμησης**: ενέργεια, ένταση, σκοτεινότητα, ρόλο στο set, κατάσταση, υποείδος, σημειώσεις, cues και σημειώσεις μετάβασης.

- Δεν διαγράφει, δεν μετακινεί και δεν αλλάζει tags στα αρχεία ήχου.
- Δεν γράφει, δεν μετακινεί και δεν κλειδώνει αρχεία εφαρμογών DJ.
- Οι σαρώσεις είναι μόνο για ανάγνωση. Οι εξαγωγές γράφουν στον φάκελο εξόδου που έχεις ορίσει, ποτέ στη βιβλιοθήκη με τη μουσική.
- Τα διπλότυπα επισημαίνονται σε ομάδες προς έλεγχο. Δεν διαγράφονται ποτέ αυτόματα.
- Η εισαγωγή από το djay Pro είναι προαιρετική και μόνο για ανάγνωση: η βάση του djay διαβάζεται από ιδιωτικό αντίγραφο και τα αρχεία ανάλυσης διαβάζονται επί τόπου.
- Κατά την εκκίνηση δημιουργείται αντίγραφο ασφαλείας της βάσης, το πολύ ένα ανά κυλιόμενο 24ωρο. Όταν η βιβλιοθήκη βρίσκεται σε φάκελο δεδομένων (η desktop εφαρμογή ή η web με `CRATEMIND_DATASET_ROOT`), δημιουργείται πάντα νέο αντίγραφο πριν από εκκρεμή αναβάθμιση σχήματος της βάσης. Διατηρούνται 3 αντίγραφα από προεπιλογή· το πλήθος ρυθμίζεται με `CRATEMIND_BACKUP_KEEP` (το `.env.example` ορίζει 10).

## Δυνατότητες

### Βιβλιοθήκη και αναζήτηση

- Σάρωση φακέλων με ανάγνωση tags (mutagen), και προαιρετικά ffprobe (διάρκεια, codec, bitrate), Chromaprint/`fpcalc` (ακουστικά αποτυπώματα) και `ffmpeg` (ανάλυση BPM/key). Τα εργαλεία ανιχνεύονται αυτόματα στο `PATH` και στο web δεν είναι υποχρεωτικά· η desktop εφαρμογή τα περιλαμβάνει.
- Κάθε κομμάτι έχει μοναδικό `id` και μοναδική διαδρομή. Τα αποτυπώματα βοηθούν στον εντοπισμό διπλοτύπων· η μετακίνηση αρχείου δεν εγγυάται αυτόματη επανασύνδεση με την παλιά εγγραφή.
- Σελίδες: Πίνακας, Βιβλιοθήκη, Καλλιτέχνες, Crates, Sets / Playlists, Ουρά tagging, Χτίσιμο set, Flow Finder, Energy Maps, Key & Harmony, Tag Cloud, Διπλότυπα και Ρυθμίσεις.
- Διπλότυπα με έλεγχο από τον χρήστη, χωρίς αυτόματη διαγραφή.
- Γλώσσα αναζήτησης με φίλτρα πεδίων και ελεύθερο κείμενο (FTS5).
- Memory Crates: αποθηκευμένες ζωντανές αναζητήσεις.
- Παλέτα εντολών με ⌘K (Ctrl+K στα Windows) και φύλλο συντομεύσεων πληκτρολογίου με `?`.

Παραδείγματα αναζήτησης:

```
energy:7-9 darkness:6-10 role:peak bpm:148-155 status:approved
```
Κομμάτια υψηλής ενέργειας και σκοτεινά, για την κορύφωση του set, 148–155 BPM, ήδη εγκεκριμένα.

```
mandragora status:approved -retired
```
Ελεύθερο κείμενο μαζί με φίλτρο κατάστασης· το `-retired` αποκλείει τα αποσυρμένα.

```
status:approved darkness:7+ not_recent:30
```
Εγκεκριμένα, σκοτεινά κομμάτια που δεν έχουν παιχτεί τις τελευταίες 30 ημέρες.

Η πλήρης αναφορά σύνταξης βρίσκεται στο [`docs/README.md#search-syntax`](docs/README.md#search-syntax).

### Tagging

- Ουρά tagging που δουλεύει με το πληκτρολόγιο (`/tag`): ενέργεια, ένταση, σκοτεινότητα, μελωδία, ρόλος, κατάσταση και άλλα.
- Υποείδη psytrance με εύρη BPM και περιγραφές: Goa Trance, Prog-psy, Full-On, Morning/Night Full-On, Twilight, Darkpsy, Forest, Hi-Tech, Psycore, Zenonesque.
- Cues ακρόασης (Entry, Exit, Cue) που ορίζονται την ώρα που ακούς το κομμάτι.
- Ακρόαση του κομματιού της ουράς στο deck A ή B.

### Sets και προτάσεις

- Χτίσιμο set (`/sets`) με καμπύλες BPM, ενέργειας και σκοτεινότητας και προειδοποιήσεις για απότομες μεταβάσεις.
- Διαφανές σύστημα προτάσεων. Δεν είναι «AI»: είναι σταθμισμένη βαθμολογία, και κάθε πρόταση δείχνει τους θετικούς και αρνητικούς λόγους της. Χρησιμοποιεί τον τροχό Camelot για αρμονική συμβατότητα.
- Λειτουργία γέφυρας (bridge mode): ζητάς κομμάτι που οδηγεί από το Track A στο Track B.
- Σημειώσεις μετάβασης ανά ζεύγος κομματιών, με βαθμολογία. Ένα ζεύγος χωρίς βαθμολογία παίρνει μικρό θετικό πλεονέκτημα, βαθμολογία 3 και άνω το αυξάνει ακόμη περισσότερο, ενώ βαθμολογία 1–2 (σύγκρουση) αφαιρεί βαθμούς από την πρόταση.
- «Σήμανση set ως παιγμένο»: καταγράφει τις αναπαραγωγές, ώστε να λειτουργούν τα φίλτρα `not_recent`.
- Εξαγωγές: M3U8, CSV, JSON backup και Markdown. Για πλήρη επαναφορά από το JSON backup χρειάζεται μαζί και ο συνοδευτικός φάκελος `<όνομα>.bundles`.

### Μίξη set

Κάθε ζεύγος διαδοχικών tracks ενός set έχει μια μετάβαση που μπορείς να δεις, να ακούσεις και να αλλάξεις, και το set παίζει ως μία συνεχής μίξη στα δύο decks.

- **Pill μετάβασης** ανάμεσα στα tracks του «Χτίσιμο set»: δείχνει το preset (π.χ. «Αυτόματο · Ανάμειξη» ή «Ανάμειξη» για αποθηκευμένη μετάβαση) και, στο tooltip, γιατί επιλέχθηκε (κλειδί, απόσταση BPM, προφίλ). Το ▶ δίπλα του κάνει προεπισκόπηση. Ένα track AIFF δείχνει «δεν παίζει στα decks».
- **«Αυτόματο»** είναι διαφανής κανόνας, όχι «AI»: ίδιο ή συμβατό κλειδί και BPM σε απόσταση έως 3 % → «Ανάμειξη»· συμβατό κλειδί → «Απόηχος»· αλλιώς «Ξεθώριασμα». Αν το επόμενο track θέλει αλλαγή tempo πάνω από 16 %, γίνεται «Κόψιμο» σε 1 bar χωρίς ταίριασμα tempo. Οι ρόλοι μετάβασης του προφίλ (`safe_blend`, `dramatic_cut`) και τα «βγαίνει με cut-out» / «δέχεται cut-in» μπορούν να το αλλάξουν.
- **«Επεξεργασία μετάβασης»** (κλικ στο pill): overview και των δύο tracks, διπλή κυματομορφή με γραμμές μέτρων και τις καμπύλες ένταση/EQ/φίλτρο πάνω της, και παράθυρο N bars που σέρνεται. Κάθε σύρσιμο έχει και εναλλακτική με ένα κλικ ή πληκτρολόγιο: επιλογή διάρκειας και ±1 bar, κουμπιά bar/beat για το παράθυρο και για την είσοδο του επόμενου track, ← → (beat), Shift+← → (bar), Alt+← → (είσοδος), `[` `]` (διάρκεια). Presets: «Αυτόματο», «Ξεθώριασμα», «Άνοδος», «Ανάμειξη», «Κύμα», «Λιώσιμο», «Κόψιμο», «Διάλυση», «Έκρηξη», «Απόηχος», «Χωρίς μετάβαση»· κάθε αλλαγή παραμέτρου (ένταση, EQ, φίλτρο, loop, διάρκεια) το κάνει «Προσαρμογή». «Ταίριασμα tempo» φέρνει το επόμενο track στο tempo του τρέχοντος. «Προεπισκόπηση» (ή Space) παίζει τη μετάβαση στα decks από 4 bars πριν το παράθυρο. «Αποθήκευση» την κρατά για αυτό το set· «Επαναφορά σε Αυτόματο» τη σβήνει.
- **«Αναπαραγωγή ως μίξη»** στην κεφαλίδα του set: το πρώτο track παίζει στο Deck A, το επόμενο περιμένει στο B και κάθε μετάβαση εκτελείται ακριβώς στον χρόνο του ήχου. Το επόμενο track ξεκινά στο tempo του τρέχοντος και επιστρέφει στο δικό του σε 8 bars. Το key lock είναι ανοιχτό και στα δύο decks όσο κρατά η μίξη και επανέρχεται στις δικές σου ρυθμίσεις στο τέλος.
- **Γραμμή κατάστασης** πάνω από τα decks: «τώρα» / «επόμενο», αντίστροφη μέτρηση ως τη μετάβαση, «ετοιμασία…» λίγο πριν, «Παράλειψη» (η μετάβαση ξεκινά στο επόμενο μέτρο) και «Διακοπή» (η αναπαραγωγή συνεχίζει). Αν αλλάξεις μόνος σου track σε deck, η μίξη σταματά· αν αλλάξεις τη σειρά του set ενώ παίζει, η μίξη ακολουθεί τη νέα σειρά.
- Αποθηκεύονται μόνο οι μεταβάσεις (πίνακας `set_transitions`) και εγγραφές στο audit log. Τα αρχεία ήχου, τα tags, τα cues, τα beatgrids και τα δεδομένα του djay δεν αλλάζουν.

### Δύο decks και mixer

Η λειτουργία δύο decks (δύο ταυτόχρονα κομμάτια) περιλαμβάνει mixer στο στυλ του djay. Ενεργοποιείται όταν φορτώσεις κομμάτι στο Deck B (π.χ. με το «→ Deck B» στη Βιβλιοθήκη) ή όταν συνδεθεί ο controller.

- Στην οθόνη: EQ HIGH/MID/LOW, FILTER, TRIM, VU meter με πραγματική μέτρηση στάθμης, faders καναλιών και crossfader· pitch fader με κουμπιά pitch bend που αλλάζουν σταδιακά το tempo, όπως στο djay· 8 hot-cue pads ανά deck (ορισμός, μεταπήδηση, διαγραφή) και eject.
- Μόνο από τον controller (άρα μόνο στην desktop εφαρμογή): master, εύρος pitch ±8/16/50 %, key lock, Sync, κουμπί cue και loops. Το Sync ευθυγραμμίζει μόνο το tempo, όχι τη φάση.

Η αναπαραγωγή στα δύο decks αποκωδικοποιεί το κομμάτι και χρησιμοποιεί τη μηχανή Signalsmith Stretch (WASM), ώστε να δουλεύουν το pitch και το key lock στο WebKit. Πάνω από 400 MiB αποκωδικοποιημένου ήχου, η αναπαραγωγή γίνεται στην αρχική ταχύτητα, χωρίς pitch, key lock ή loop.

### Κυματομορφές και beatgrid

- Πάνελ κυματομορφής ανά deck, που κυλά, με χρώματα τριών ζωνών: «Θέμα (κυανό / μωβ)» (προεπιλογή) ή «Συχνότητες (djay)» (Ρυθμίσεις › Εμφάνιση).
- Γραμμές beat και μέτρου με αρίθμηση μέτρων, ζουμ 2–32 μέτρα, μεταπήδηση με κλικ και scrub με σύρσιμο.
- Κεφαλίδα deck με εξώφυλλο, τίτλο, καλλιτέχνη, BPM, key, υπολειπόμενο χρόνο και overview.
- Η «Θέση κυματομορφών decks» (Ρυθμίσεις) ορίζει αν το πάνελ μπαίνει στην κορυφή (προεπιλογή) ή πάνω από τα decks. Η κάτω μπάρα των decks μπορεί να συμπτυχθεί.
- **Beatgrid από το djay Pro** (Ρυθμίσεις › «Beatgrid από djay»): προαιρετική εισαγωγή μόνο για ανάγνωση, δοκιμασμένη με djay Pro 5.6.9 (μορφή ανάλυσης v8). Οι προεπιλεγμένες διαδρομές είναι οι διαδρομές του djay στο macOS και ρυθμίζονται. Αντιστοιχίζει εγγραφές του djay με κομμάτια που υπάρχουν ήδη στον κατάλογο του CrateMind, με βάση τη διαδρομή αρχείου ή, αλλιώς, το όνομα αρχείου και τη διάρκεια (±1 s)· οι αμφίσημες αντιστοιχίσεις παραλείπονται. Εισάγει ευθύ grid και τις θέσεις beat του djay για κομμάτια με μεταβλητό tempo. Παραλείπει grids που έχουν επεξεργαστεί στο djay με τρόπους που δεν υποστηρίζονται ακόμη, κομμάτια που δεν είναι σε 4/4 και άγνωστες εκδόσεις ανάλυσης, και δείχνει αναφορά.
- Κομμάτια χωρίς grid από το djay παίρνουν εκτιμώμενο grid, σημειωμένο ως «εκτίμηση». Η εκτίμηση χρειάζεται έγκυρο BPM και ξεκινά από το entry cue ή από το 0:00.
- **Εργαλείο downbeat**: επικάλυψη DOWNBEAT σε κάθε κυματομορφή, με «Ορισμός» (θέτει το μέτρο 1 στη θέση του playhead· σε εκτιμώμενο grid σταθεροποιεί τη φάση των beat στο playhead, ενώ σε εισαγόμενο grid προσαρμόζεται στο πλησιέστερο beat), ◀ ▶ (μετακίνηση του μέτρου 1 κατά ένα beat) και επαναφορά. Η αρίθμηση των μέτρων μένει κοντά στην αρχική αφετηρία. Αποθηκεύεται μόνο στο CrateMind, ποτέ στο djay.

### Controller

Υποστηρίζεται το Numark Mixtrack Platinum FX, **μόνο στην desktop εφαρμογή**: το MIDI το χειρίζεται το εγγενές κέλυφος (Tauri) και η web εφαρμογή δεν έχει MIDI.

- Transport, cue, pads, pitch/bend, EQ/filter/trim/master, Sync και loops.
- Περιήγηση και φόρτωση από την ενεργή λίστα (Βιβλιοθήκη, ουρά tagging και οι δύο λίστες του Χτισίματος set), με την αναπαραγωγή να πηγαίνει σε ελεύθερο deck.
- Ομάδες pad (banks) για γρήγορη βαθμολόγηση ενέργειας και σκοτεινότητας (1–8) και ορισμό κατάστασης, και FX select για σημειώσεις μετάβασης (καλή / μέτρια / σύγκρουση).
- Feedback με LED.

### Desktop και web

| | Desktop | Web (περιβάλλον ανάπτυξης) |
|---|---|---|
| Τεχνολογία | Tauri 2, ενσωματωμένο Python backend | FastAPI στο `:8000` + Vite στο `:5173` |
| Controller (MIDI) | Ναι | Όχι |
| Υπολογισμός BPM/key | Ναι, τοπικά και χωρίς online υπηρεσίες | Ναι (χρειάζεται `ffmpeg`) |
| Εργασίες παρόχων (SoundCloud/Spotify) | Όχι, μένουν διαθέσιμα τα αποθηκευμένα αποτελέσματα | Ναι, όπου είναι ενεργές |

Οι σελίδες που αφορούν ταυτότητα και συλλογές (Συλλογές, Προέλευση συλλογών, Πληρότητα & ανάκτηση, Μεταδεδομένα & καλλιτέχνες, Ενοποιημένη βιβλιοθήκη) εμφανίζονται μόνο όταν το backend δηλώνει την αντίστοιχη δυνατότητα (capability) κατά την εκκίνηση. Οι σελίδες «Έξυπνοι φάκελοι» και «Phrase Finder» είναι προς το παρόν σελίδες «σύντομα» και δεν έχουν λειτουργικότητα. Περισσότερα στο [`docs/TAURI_DESKTOP_OPERATIONS.md`](docs/TAURI_DESKTOP_OPERATIONS.md).

Για να μοιραστούν η web και η desktop εφαρμογή την ίδια βιβλιοθήκη, όρισε στο `.env` της web το `CRATEMIND_DATASET_ROOT` στον φάκελο δεδομένων της desktop εφαρμογής. Τότε μπορεί να την ανοίξει μόνο μία εφαρμογή τη φορά.

## Εκκίνηση

Προϋποθέσεις: Python ≥ 3.12 με [uv](https://docs.astral.sh/uv/) και [bun](https://bun.sh/). Για ανάλυση BPM/key στο web χρειάζεται `ffmpeg` στο `PATH`.

Backend (FastAPI):

```bash
cd backend
uv sync
cp ../.env.example .env        # όρισε CRATEMIND_LIBRARY_ROOTS στους φακέλους της μουσικής σου
uv run uvicorn app.main:app --reload --port 8000   # τεκμηρίωση API στο /docs
```

Frontend (React 19, TypeScript, Vite 8):

```bash
cd frontend
bun install
bun run dev                     # http://localhost:5173, προωθεί το /api στο :8000
```

Και οι δύο servers πρέπει να τρέχουν μαζί, γιατί το frontend δεν έχει δεδομένα χωρίς το backend.

Έλεγχοι:

```bash
(cd backend && uv run pytest)    # δοκιμές backend
(cd frontend && bun run build)   # tsc --noEmit && vite build, χρησιμοποιείται και ως έλεγχος τύπων
```

### Desktop εφαρμογή (macOS)

Η desktop εφαρμογή λέγεται «CrateMind Preview» και χτίζεται με Tauri 2 από τον φάκελο `native/`. Είναι υπογεγραμμένη μόνο ad-hoc (όχι με Developer ID), οπότε το Gatekeeper εμφανίζει προειδοποίηση. Απαιτεί macOS 15 ή νεότερο και χτίζεται και δοκιμάζεται μόνο σε Apple Silicon. Τα βήματα build, οι έλεγχοι και η μεταφορά υπαρχόντων δεδομένων web περιγράφονται στο [`docs/TAURI_DESKTOP_OPERATIONS.md`](docs/TAURI_DESKTOP_OPERATIONS.md).

### Windows

Το workflow `.github/workflows/windows.yml` χτίζει στο GitHub Actions έναν **ανυπόγραφο** εγκαταστάτη Windows x64, σε κάθε push στον κλάδο `windows-build` ή χειροκίνητα. Ο εγκαταστάτης (`.exe`) βρίσκεται στο artifact `cratemind-windows-x64` της εκτέλεσης (κατεβαίνει ως .zip· χρειάζεται σύνδεση στο GitHub). Το SmartScreen θα εμφανίσει προειδοποίηση· επίλεξε «Περισσότερες πληροφορίες» και μετά «Εκτέλεση οπωσδήποτε». Η εφαρμογή ξεκινά με κενή βιβλιοθήκη και δεν έχει δοκιμαστεί ακόμη σε πραγματικό υπολογιστή με Windows.

## Περιορισμοί

- Ένας χρήστης, μόνο τοπικά: χωρίς λογαριασμούς και χωρίς συγχρονισμό στο cloud.
- Οι εκδόσεις macOS Preview και Windows δεν έχουν επίσημη υπογραφή (μόνο ad-hoc στο macOS), οπότε εμφανίζονται προειδοποιήσεις Gatekeeper/SmartScreen. Τα Windows δεν έχουν δοκιμαστεί σε πραγματικό υπολογιστή. Δεν υπάρχει έκδοση για Linux.
- Το περιβάλλον χρήστη είναι μόνο στα ελληνικά· ορισμένα κείμενα είναι ακόμη στα αγγλικά.
- Ο controller περιορίζεται σε ένα μοντέλο και μόνο στην desktop εφαρμογή.
- Δεν υπάρχει δική του ανάλυση beat/downbeat: τα grids προέρχονται από το djay ή είναι εκτιμώμενα. Δεν υπάρχει ακόμη λεπτή μετατόπιση του grid ούτε διόρθωση BPM.
- Τα cues του djay δεν εισάγονται.
- Η εισαγωγή από το djay υποστηρίζει μία μορφή ανάλυσης (v8) και μόνο κομμάτια 4/4, και αντιστοιχίζει μόνο κομμάτια που υπάρχουν ήδη στη βιβλιοθήκη του CrateMind.
- Το Sync ευθυγραμμίζει μόνο το tempo (όχι τη φάση). Δεν υπάρχει jog nudge ούτε scratch. Τα αρχεία AIFF/AIF δεν αναπαράγονται μέσα στην εφαρμογή. Η αίσθηση του pitch bend ρυθμίζεται ακόμη.
- Το pitch στα δύο decks απαιτεί ολόκληρο το κομμάτι αποκωδικοποιημένο στη μνήμη· πάνω από 400 MiB παίζει χωρίς pitch, key lock ή loop.
- Μίξη set: όταν το ίδιο track υπάρχει δύο φορές σε ένα set, οι δύο εμφανίσεις μοιράζονται μία μετάβαση. Δεν υπάρχει σειρά εφέ (effects). Tracks που παίζουν χωρίς τη μηχανή stretch (πάνω από 400 MiB ή αποτυχία αποκωδικοποίησης) αλλάζουν με απλό cut, και τα AIFF παραλείπονται από τη μίξη. Η ευθυγράμμιση της φάσης είναι τόσο καλή όσο το grid: ένα εκτιμώμενο grid μπορεί να απέχει έως μισό beat. Η επιστροφή του tempo μετά τη μετάβαση γίνεται σε βήματα των 50 ms. Μια κίνηση του crossfader ή του EQ την ώρα της μετάβασης προστίθεται στην αυτόματη μίξη (δεν την ακυρώνει· η «Διακοπή» την ακυρώνει).
- Η desktop εφαρμογή υπολογίζει BPM/key μόνο τοπικά. Ο έλεγχος BPM με online υπηρεσίες (ReccoBeats, GetSongBPM, Cyanite), η αντίστοιχη κάρτα στις Ρυθμίσεις και η ανάλυση με Essentia υπάρχουν μόνο στο web.
- Κοινή βιβλιοθήκη web και desktop: απαιτεί `CRATEMIND_DATASET_ROOT` και μία εφαρμογή τη φορά.
- Ορισμένες προαιρετικές λειτουργίες του web χρησιμοποιούν online υπηρεσίες, όλες ρυθμισμένες στο `.env`: έλεγχος BPM μέσω ReccoBeats (ενεργός από προεπιλογή· κατά την ανάλυση ήχου στέλνει σύντομο απόσπασμα ήχου στην υπηρεσία, εκτός αν οριστεί `CRATEMIND_RECCOBEATS_ENABLED=false`), GetSongBPM και Cyanite (απενεργοποιημένα, χρειάζονται κλειδί API), εμπλουτισμός καλλιτεχνών μέσω ρυθμισμένου LLM και εργασίες SoundCloud/Spotify.

## Οδικός χάρτης

Πρόκειται για προθέσεις, όχι για δεσμεύσεις.

**Σύντομα**

- Jog nudge και ρύθμιση του pitch bend.
- Δεύτερη φάση της προβολής decks: ανασχεδιασμός περιοχής pitch/SYNC, γραμμή εργαλείων για τα pad modes, γραμμή transport και εναλλακτική οριζόντια διάταξη των decks.
- Δική του ανάλυση beat/downbeat και επεξεργασία grid (λεπτή μετατόπιση, διόρθωση BPM).
- Εισαγωγή cues από το djay, πληρέστερη υποστήριξη επεξεργασμένων grids του djay και αντιστοίχιση των keys του djay στο Camelot.
- Ρυθμιζόμενη λίστα υποειδών.
- Επικαλύψεις loop στην κυματομορφή.
- Προβολή ιστορικού σαρώσεων.
- Μετάφραση στα ελληνικά των κειμένων που έμειναν στα αγγλικά.

**Αργότερα**

- Υπογεγραμμένες εκδόσεις, βελτίωση των Windows και ίσως Linux.
- Ιδέες καταλόγου από το [`docs/ROADMAP_AND_IDEAS.md`](docs/ROADMAP_AND_IDEAS.md): ενιαίο ράφι πηγών (τοπικά αρχεία, SoundCloud, Spotify), οθόνη σύγκρισης για έλεγχο αντιστοιχίσεων, ετοιμότητα set χωρίς σύνδεση, επανανακάλυψη και «χαμένα αγαπημένα», καμπύλη set που λαμβάνει υπόψη πόσο γνωστά είναι τα κομμάτια, επιλεκτική μονόδρομη δημοσίευση.
